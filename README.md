# Environmental Telemetry Platform

A Kubernetes-based platform for collecting, storing, and analyzing real-world environmental sensor data.

The project uses public environmental APIs, beginning with the U.S. Geological Survey (USGS), to explore infrastructure engineering, container orchestration, observability, and cloud integration.

## Technology Stack

- **Languages:** Python, Go
- **API:** FastAPI
- **Database:** PostgreSQL / PostGIS
- **Infrastructure:** Kubernetes, Docker, Terraform
- **Cloud:** Google Cloud Platform (GCS)
- **Observability:** Prometheus, Grafana, OpenTelemetry

## Project Status

**Work in Progress**

Currently in early development, focusing on USGS data ingestion, validation, and normalization.

Additional functionality and infrastructure will be introduced incrementally as the project develops.
